# Event Studio agentic mode

Read repository `AGENTS.md` and [the workflow routes and execution contract](../../../.codex/workflows.md). Choose the route matching the requested outcome; use appropriate subagents for independent substantial work. Direct execution is sufficient for small tasks.

Keep a short plan for multi-step work. Assign specific files and outcomes to specialists, pass forward findings, integrate changes, verify behavior, and resolve actionable review findings. Continue all authorized phases without routine confirmation gates. Do not turn a request to analyze, plan, review, or audit into permission to edit or deploy.

If the runtime does not support delegation or custom roles, follow the documented fallback. Report actual evidence and remaining blockers; never describe simulated steps as completed subagent runs.
